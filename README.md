
# PhotoShare

Aplicación web para compartir fotografías, desarrollada como proyecto académico de Sistemas Distribuidos.

## Tecnologías
- React y Vite
- Node.js y Express
- MySQL
- JWT y bcryptjs
- Multer

## Funcionalidades
- Registro de usuarios
- Inicio de sesión
- Publicación de fotografías
- Galería de fotografías
- Almacenamiento de información en MySQL

## Instalación

### Base de datos
Importar `photoshare.sql` en MySQL.

### Backend
1. Entrar en la carpeta backend.
2. Ejecutar `npm install`.
3. Configurar las variables de entorno en `.env`.
4. Ejecutar `node server.js`.

### Frontend
1. Entrar en la carpeta frontend.
2. Ejecutar `npm install`.
3. Ejecutar `npm run dev`.
4. Abrir http://localhost:5173
